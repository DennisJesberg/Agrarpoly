# AGRARPOLY V2.13

Änderung gegenüber V2.12:
- Wenn der aktuelle Spieler eine Ereigniskarte aufdeckt, sehen **alle verbundenen Spieler** sofort ein zentriertes Popup mit der gewählten Karte.
- Das Popup zeigt Titel, Kartentext und – falls vorhanden – den Punktwert.
- Das Popup erscheint nur einmal pro neu aufgedeckter Karte und bleibt sichtbar, bis der Spieler es mit „OK – KARTE GESEHEN“ schließt oder der Master mit WEITER die Ereigniskartenphase beendet.
- Die bisherige Kartenauswahl 5×4 und die Spiellogik bleiben unverändert.
