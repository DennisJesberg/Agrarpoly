## Render
1. ZIP entpacken und den Inhalt in das GitHub-Repository übernehmen.
2. Root Directory leer lassen, wenn `package.json` und `server.js` im Repository-Hauptverzeichnis liegen.
3. Build Command: `npm install`
4. Start Command: `npm start`

Nur eine README-Datei ist enthalten.
