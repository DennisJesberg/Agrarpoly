## Render
1. ZIP entpacken und den Inhalt ins GitHub-Repository übernehmen.
2. Render: Root Directory leer lassen, wenn `package.json` und `server.js` im Repository-Hauptverzeichnis liegen.
3. Build Command: `npm install`
4. Start Command: `npm start`

## Hinweis
Nach dem Deploy einmal einen Hard-Refresh im Browser durchführen (Strg+F5), damit das neue Headerbild sicher geladen wird.
